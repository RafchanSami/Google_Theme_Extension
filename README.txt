NEO THEME STUDIO - CYBER DEVELOPER
Created by Rafchan Sami

INSTALLATION (Google Chrome / Microsoft Edge)
1. Extract Neo-Theme-Studio.zip to a folder.
2. Open chrome://extensions/ in Chrome.
3. Turn on Developer mode (top-right).
4. Click Load unpacked.
5. Select the extracted Neo-Theme-Studio folder (the folder containing manifest.json).
6. Open a new tab to see the theme.

FEATURES
- Animated Matrix-style programming code rain.
- Moving neon code ticker at the bottom.
- Animated ambient glow and blinking cursor.
- Google search and direct URL navigation.
- Developer shortcuts: GitHub, VS Code, Stack Overflow, YouTube and MDN.
- Live clock and date.
- Pause / resume effects button.
- Responsive layout and reduced-motion support.

NOTES
- No special permissions or account access are requested.
- Google Fonts are loaded from the internet; system fonts are used if unavailable.
- The extension replaces the New Tab page. It does not change Chrome's toolbar colors like a traditional Chrome theme package.
